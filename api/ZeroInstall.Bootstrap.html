Namespace ZeroInstall.Bootstrap

Code for bootstrapping Zero Install, i.e., downloading and running a full version of Zero Install from a small executable.

Classes

BootstrapConfig

Represents configuration bundled with the bootstrapper. This can be used to create a customized bootstrapper that uses Zero Install to run or integrate another application.

BootstrapProcess

Represents the process of downloading and running an instance of Zero Install. Handles command-line arguments.

CliBootstrapHandler

Informs the user about the progress of tasks and ask questions during the bootstrap process using console output.

ProgramUtils

Provides utility methods for application entry points.

Interfaces

IBootstrapHandler

Used to run and track ITasks and ask the user questions during the bootstrap process.

Enums

ExitCode

An exit code is returned to the original caller after the application terminates, to indicate success or the reason for failure.
