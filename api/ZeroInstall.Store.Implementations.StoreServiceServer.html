Class StoreServiceServer

Namespace
ZeroInstall.Store.Implementations

Accepts implementations from ServiceImplementationSinks via a named pipe and adds them to machine-wide implementation directories. Intended to be hosted by a Windows service running as LocalSystem.

public sealed class StoreServiceServer : IDisposable
Inheritance
object
StoreServiceServer
Implements
IDisposable

Remarks

Clients are untrusted. They send a stream of build operations which are validated and applied to a temporary directory. The service calculates the manifest digest itself and only commits the implementation if it matches.
