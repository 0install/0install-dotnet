Copies all implementations in a Selections document into a directory and generates a launcher script that sets up the environment the same way Executor would. The resulting directory can be run without Zero Install and can be moved to a different location.

Properties

Clean

Remove content from earlier runs that is no longer needed: implementations that are no longer selected and unneeded files in ZeroInstall.Services.Executors.LauncherScriptBuilder.BinDir. Also replace existing copies with links or vice versa to match UseLinks.

public bool Clean { get; init; }

Property Value

bool

Remarks

Without this, existing files are left as-is, apart from the ones being regenerated.

Remarks

Methods

Materialize(Selections, string, string)

Materializes a set of selections into a directory.

public string Materialize(Selections selections, string targetDir, string launcherName)

Parameters

selections Selections

The selections to materialize. All implementations must already be cached.

targetDir string

The directory to place the implementations and launcher scripts in. Created if it does not exist yet.

launcherName string

The file name for the main launcher script, without a file extension.

Returns

string

The full path of the file to run to start the program, including a file extension if TargetOS requires one.
