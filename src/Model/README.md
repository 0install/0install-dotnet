# ZeroInstall.Model

Data model for the Zero Install [feed format](https://docs.0install.net/specifications/feed/).

[Zero Install](https://0install.net/) is a decentralized cross-platform software installation system. This package is part of the [.NET implementation](https://github.com/0install/0install-dotnet) of Zero Install.

The `ZeroInstall.Model` namespace contains the data model for the feed format with the `Feed` class as the entry point. The `ZeroInstall.Model.Capabilities` namespace contains the data model for the [capabilities extension](https://docs.0install.net/specifications/capabilities/).
