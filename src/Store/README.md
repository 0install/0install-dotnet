# ZeroInstall.Store

Management of Zero Install [implementation caches](https://docs.0install.net/details/cache/), digital signatures, etc.

[Zero Install](https://0install.net/) is a decentralized cross-platform software installation system. This package is part of the [.NET implementation](https://github.com/0install/0install-dotnet) of Zero Install.

The `ZeroInstall.Store` namespace provides the building blocks that Zero Install's higher-level services are built upon.
