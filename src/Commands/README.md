# ZeroInstall.Commands

Command-line interface for Zero Install.

[Zero Install](https://0install.net/) is a decentralized cross-platform software installation system. This package is part of the [.NET implementation](https://github.com/0install/0install-dotnet) of Zero Install.

The binary in this package serves both as an actual CLI (`0install`) and as a library for building other clients.

**[Additional documentation](https://dotnet.0install.net/cli.html)**
