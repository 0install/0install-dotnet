# ZeroInstall.Publish

Utilities for creating and modifying feed files.

[Zero Install](https://0install.net/) is a decentralized cross-platform software installation system. This package is part of the [.NET implementation](https://github.com/0install/0install-dotnet) of Zero Install.

This provides the basis for the [graphical feed editor](https://docs.0install.net/tools/0publish-gui/). You can also use it to automate complex feed creation/update tasks or to create your own tools.

**[Additional documentation](https://dotnet.0install.net/publish.html)**
