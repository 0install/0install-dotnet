uid: ZeroInstall.Commands.EtoForms
summary: Cross-platform Eto.Forms-based GUI for Zero Install, for installing and launching applications, managing caches, etc..
---
> [!NOTE]
> NuGet package: [ZeroInstall.Commands.EtoForms](https://www.nuget.org/packages/ZeroInstall.Commands.EtoForms/)

Pass a <xref:ZeroInstall.Commands.EtoForms.GuiCommandHandler> to <xref:ZeroInstall.Commands.ProgramUtils> inside a running Eto.Forms application. This library contains no Eto.Forms platform backend; reference the appropriate `Eto.Platform.*` package in your application.
